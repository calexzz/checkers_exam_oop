# Пояснительная записка
## Объектная модель решателя задач «Шашки»

---

## 1. Введение

Программа реализует решатель шашечных позиций - читает позицию из файла и находит победную последовательность ходов для одной из сторон.

---

## 2. Описание классов и структур

### enum Color

Вспомогательный тип для различения цвета фигур. Используется везде где нужно проверить принадлежность фигуры.

- `WHITE` - белые фигуры
- `BLACK` - чёрные фигуры

---

### enum Result

Нужен для того, чтобы различать три состояния - победа белых, победа чёрных и отсутствие победы в заданную глубину.

- `WHITE_WINS` - белые выиграли, на доске нет чёрных фигур
- `BLACK_WINS` - чёрные выиграли, на доске нет белых фигур
- `NO_RESULT` - выигрыш не найден в заданную глубину

---

### struct Move - ход

Хранит всю информацию об одном ходе.

| Поле | Доступ | За что отвечает | Почему public/private |
|---|---|---|---|
| `src: Cell*` | public | Начальная клетка хода | public - нужен для работы с ходом |
| `dst: Cell*` | public | Конечная клетка хода | public - нужен для работы с ходом |
| `moveColor: Color` | public | Цвет фигуры которая ходит | public - нужен Game для вывода чей ход |
| `wasPromotion: bool` | public | Флаг превращения шашки в дамку | public - нужен Board::undoMove для отмены превращения |
| `captured: vector<Cell*>` | public | Координаты клеток срубленных фигур | public - нужен Board::applyMove и undoMove |
| `capturedFigures: vector<Figure*>` | public | Сами объекты срубленных фигур | public - нужен Board::undoMove чтобы вернуть конкретные фигуры |
| `path: vector<Cell*>` | public | Промежуточные клетки при серии взятий | public - нужен Game::printResult для вывода маршрута |

---

### struct Cell - клетка

Хранит состояние одной клетки доски.

| Имя | Доступ | За что отвечает | Почему public/private |
|---|---|---|---|
| `x, y: int` | public | Координаты клетки на доске | public - нужны Checker и Queen при генерации ходов |
| `figure: Figure*` | public | Фигура стоящая на клетке или nullptr | public - потому что к нему обращаются Board при загрузке и передвижении фигур, а также Checker и Queen при генерации ходов. |
| `isEmpty()` | public | Проверяет пуста ли клетка | public - используется при генерации обычных ходов |
| `hasEnemy(color)` | public | Проверяет стоит ли на клетке враг | public - используется при поиске взятий |

---

### class Board - игровое поле

Хранит текущее состояние доски и отвечает за все операции с позицией - загрузку, применение и отмену ходов, генерацию всех возможных ходов.

| Имя | Доступ | За что отвечает | Почему public/private |
|---|---|---|---|
| `cells: Cell[8][8]` | private | Массив из 64 клеток - основное хранилище доски | private - внутренняя структура, снаружи доступ через getCell() |
| `loadPieces(file, color)` | private | Читает фигуры одного цвета из файла | private - вспомогательный метод, вызывается только внутри loadFromFile |
| `Board()` | public | Инициализирует все клетки пустыми, расставляет координаты | public - нужен для создания объекта в Game |
| `loadFromFile(filename)` | public | Загружает позицию из текстового файла | public - вызывается из конструктора Game |
| `applyMove(move)` | public | Передвигает фигуру, убирает срубленных, проверяет превращение | public - вызывается из Solver::findWinningLine |
| `undoMove(move)` | public | Полностью восстанавливает доску до состояния перед ходом | public - вызывается из Solver::findWinningLine после перебора |
| `getAllMoves(color)` | public | Возвращает все возможные ходы для фигур данного цвета | public - вызывается из Solver::findWinningLine |
| `needsPromotion(cell)` | public | Проверяет нужно ли превратить шашку в дамку | public - вызывается внутри applyMove |
| `promote(cell)` | public | Заменяет объект Checker на Queen того же цвета | public - вызывается внутри applyMove |
| `noFigures(color)` | public | Проверяет нет ли на доске фигур данного цвета | public - вызывается из Solver для определения победителя |
| `getCell(x, y)` | public | Возвращает указатель на клетку по координатам | public - вызывается из Checker, Queen и findCaptures |
| `inBounds(x, y)` | public | Проверяет что координаты находятся в пределах доски | public - вызывается из Checker, Queen и findCaptures |

---

### class Figure - фигура (абстрактный)

Задаёт общий интерфейс для всех фигур. Позволяет Board работать с любой фигурой через указатель `Figure*` не зная её конкретного типа.

| Имя | Доступ | За что отвечает | Почему public/private |
|---|---|---|---|
| `color: Color` | public | Цвет фигуры | public - нужен Cell и findCaptures для проверки цвета |
| `Figure(color)` | public | Инициализирует цвет фигуры | public - вызывается из конструкторов наследников Checker и Queen |
| `virtual getMoves(board, cell)` | public | Возвращает все возможные ходы фигуры | public - вызывается из Board::getAllMoves через полиморфизм |
| `virtual ~Figure()` | public | Виртуальный деструктор | public - объекты удаляются через `Figure*`, без виртуального деструктора деструктор наследника не вызовется |

---

### class Checker : public Figure - шашка

Реализует правила движения обычной шашки - ход на одну клетку вперёд, взятие в любую сторону. Использует вспомогательную функцию `findCaptures` для поиска серий взятий.

| Имя | Доступ | За что отвечает | Почему public/private |
|---|---|---|---|
| `color` | (наследует от Figure) | Цвет фигуры | - |
| `Checker(color)` | public | Создаёт шашку заданного цвета | public - создаётся в Board::loadPieces и Board::undoMove |
| `getMoves(board, cell)` | public | Генерирует ходы шашки - взятия или обычные ходы | public - переопределяет виртуальный метод, вызывается через Figure* |

---

### class Queen : public Figure - дамка

Реализует правила движения дамки - ход на любую длину по диагонали, взятие через любую вражескую фигуру. Создаётся в `Board::promote` когда шашка достигает последней линии.

| Имя | Доступ | За что отвечает | Почему public/private |
|---|---|---|---|
| `color` | (наследует от Figure) | Цвет фигуры | - |
| `Queen(color)` | public | Создаёт дамку заданного цвета | public - создаётся в Board::promote |
| `getMoves(board, cell)` | public | Генерирует ходы дамки - взятия или обычные ходы | public - переопределяет виртуальный метод, вызывается через Figure* |

---

### class Solver - решатель

Реализует рекурсивный перебор ходов для поиска победной цепочки. Не владеет доской - получает ссылку `Board&` от Game.

| Имя | Доступ | За что отвечает | Почему public/private |
|---|---|---|---|
| `board: Board&` | private | Ссылка на игровое поле | private - внутренняя деталь, снаружи менять нельзя |
| `depth: int` | private | Глубина поиска в полуходах | private - задаётся один раз в конструкторе, менять снаружи не нужно |
| `solution: vector<Move>` | private | Найденная победная цепочка ходов | private - накапливается внутри, снаружи отдаётся через solve() |
| `winner: Color` | private | Цвет победителя | private - устанавливается внутри, снаружи читается через getWinner() |
| `Solver(board, depth)` | public | Инициализирует ссылку на доску и глубину поиска | public - создаётся в конструкторе Game |
| `solve()` | public | Запускает поиск и возвращает победную цепочку | public - вызывается из Game::run() |
| `findWinningLine(depth, color)` | public | Рекурсивно перебирает ходы и ищет победную ветку | public - основной алгоритм поиска, возвращает Result |
| `getWinner()` | public | Возвращает цвет победителя | public - вызывается из Game::printResult() |

---

### class Game - игра

Точка входа программы - связывает все компоненты, загружает позицию и выводит результат.

| Имя | Доступ | За что отвечает | Почему public/private |
|---|---|---|---|
| `board: Board` | private | Игровое поле | private - внутренняя деталь, снаружи не нужна |
| `solver: Solver` | private | Решатель | private - внутренняя деталь, снаружи не нужна |
| `history: vector<Move>` | private | История найденных ходов | private - результат работы, снаружи не нужен |
| `Game(filename, depth)` | public | Загружает позицию из файла, инициализирует Solver | public - точка входа, вызывается из main() |
| `run()` | public | Запускает решатель, сохраняет результат в history | public - вызывается из main() |
| `printResult()` | public | Выводит победителя и последовательность ходов | public - вызывается из main() |

---

## 3. Серия взятий

Серия взятий реализована через вспомогательные рекурсивные функции `findCaptures` и `findCapturesQueen`. Они не являются методами классов и не показаны на схеме - это детали реализации видимые только внутри `Checker.cpp` и `Queen.cpp`.

Вся серия прыжков представляется одним объектом Move: `src` - откуда начали, `dst` - где закончили, `captured` - все срубленные фигуры, `path` - промежуточные клетки для вывода маршрута.
